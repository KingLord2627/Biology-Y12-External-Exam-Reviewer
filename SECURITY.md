# Security Policy

## Supported Versions

Only the latest deployment on the default branch (`main`) is actively supported with security updates and fixes.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main` (Latest)  | :white_check_mark: |
| Older releases   | :x:                |

## Reporting a Vulnerability

If you find a security vulnerability or security bug in this project, please report it responsibly rather than opening a public issue.

### How to Report
1. Open a **Private Security Advisory** directly on GitHub via the **Security** tab > **Advisories** > **Report a vulnerability**.
2. Alternatively, email details directly to `king032427@gmail.com`.

### What to Include
To help assess and resolve the issue quickly, please include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal proof of concept (PoC).
- Any affected URLs, assets, or scripts.

### Response Timeline
- **Initial Acknowledgment:** You can expect an initial response within **48 hours** confirming receipt of your report.
- **Status Updates:** You will receive regular progress updates every **3–5 business days** while the issue is being investigated and patched.
- **Resolution:** If accepted, a fix will be deployed directly to the production branch, and you will be credited in the release notes if you wish.
